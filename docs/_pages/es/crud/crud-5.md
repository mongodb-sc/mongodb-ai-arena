## 🚀 Objetivo: Insertar Nuevos Documentos como un Profesional

¡Tu plataforma está creciendo y es hora de expandir tus ofertas! Imagina a un anfitrión agregando una nueva propiedad o a un huésped registrándose por primera vez. Como ingeniero backend, eres el que hace posibles estos momentos—dando vida a nuevos datos en tu colección de MongoDB.

En este ejercicio, dominarás el arte de insertar documentos. Cada nuevo listado, huésped o reserva comienza con una sola inserción—y tu código es lo que lo hace posible.

---

### 🧩 Ejercicio: Insertar un Documento

1. **Abre el Archivo**  
   Navega a `server/src/lab/` y abre `crud-5.lab.js`.

2. **Localiza la Función**  
   Encuentra la función `crudCreateItem` en el archivo.

3. **Actualiza el Código**  
   - Inserta el documento almacenado en la variable `item` en la colección.
   - La variable `item` ya está formateada y lista para la inserción.

---

### 🚦 Prueba tu API

1. Ve al directorio `server/src/lab/rest-lab`.
2. Abre `crud-5-insert-lab.http`.
3. Haz clic en **Send Request** para ejecutar la llamada a la API.
4. Verifica que la respuesta confirme la inserción exitosa del documento.
